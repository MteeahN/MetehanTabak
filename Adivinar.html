AdivinarGuessing Game

Adivinar ("to guess" in Spanish) is a numeric estimation game: every question has a number for an answer, and the closer your guess, the more points you earn. It offers a daily challenge, an unlimited mode and a serverless online multiplayer mode — all in a single HTML file.

Project Overview

How close can you get?

How many litres does a standard water jug hold? What year was the first iPhone introduced? Adivinar turns questions like these into a game where being close is rewarded, not just being right. Every guess gets a closeness score between 0 and 100, and a short explanation reveals the answer.

Players can take on 50 fresh questions every day, play endlessly by category in unlimited mode, or open a room and challenge up to three friends online — with no backend: browsers connect peer-to-peer over WebRTC.

Progress, records and statistics are kept in the browser with a versioned, migratable data layer, so returning players pick up exactly where they left off.

Problem & Solution

A fair game, a fair score — without a server.

The Challenge
Numeric answers range from grams to light years, so "how close" means something different for every question — and the multiplayer mode had to be fair without any server to referee it.
Scoring a guess fairly whether the answer is 5 grams or 384,400 km
A daily set that never repeats a question and resets at midnight, Istanbul time, on every device
Online rooms for 2–4 players with no backend, database or account system
Preventing players from seeing each other's guesses before a round is revealed
Surviving page refreshes and dropped connections in the middle of a match
Comfortable number entry on phones: thousands separators, decimals and years
The Solution
A small, pure scoring engine, a time service pinned to Istanbul and a host-authoritative peer-to-peer protocol keep every mode consistent and fair.
Closeness = 100 × (1 − distance ÷ scale), with per-question acceptance ranges and custom scales
A category-balanced daily pool of 50 questions, filtered against every question already shown
PeerJS (WebRTC) rooms with 5-character codes and invite links; the host is the single authority
Guesses stay on the host until everyone has answered — only question IDs travel over the network
Automatic guest reconnection (12 tries) and "reopen room" from local state for the host
A dedicated number input with live formatting, validation and per-question unit badges
Development Journey

From a question list to an online party game.

Phase 01
Question Bank & Scoring Engine
The project started as "Tahmin Arenası". I wrote and fact-checked 337 questions across seven categories, each with a unit, an optional acceptance range and a one-line explanation. Then I designed the scoring formula and tuned it until near misses felt rewarding but lucky guesses didn't dominate.
Content ResearchScoring FormulaAcceptance Ranges
Phase 02
Daily & Unlimited Modes
I built the daily challenge on a time service fixed to Europe/Istanbul, so the day flips at the same moment everywhere. Questions are marked as used the moment they appear, and unlimited mode draws from the bank independently with a category picker and personal records.
Time Zone HandlingCategory-Balanced PoolsSession State
Phase 03
Data Layer & Statistics
All progress lives in a versioned localStorage store with a backup key and a migration path from the old "Tahmin Arenası" data, so no player lost progress after the rename. A statistics view summarises accuracy per question and per category with lightweight, dependency-free charts.
Versioned StorageData MigrationSVG Charts
Phase 04
Online Multiplayer over WebRTC
The last phase added real-time rooms with PeerJS. The host picks the questions, collects guesses, scores the round and broadcasts room state; guests only send their answer. Player colours, round counts (5–20), a live scoreboard, invite links and reconnection logic turned it into a game you can play with friends from any phone.
